# Reels Factory

Локальный пайплайн для автоматического монтажа коротких вертикальных видео (Reels/Shorts): транскрипция с пословным таймингом, нарезка по паузам, субтитры, вставки b-roll — всё бесплатно и офлайн, без сторонних сервисов.

Идея пайплайна вдохновлена практиками автоматизации контента на нейросетях, но весь код в этом репозитории написан с нуля под собственные нужды.

## Что внутри

- `tools/transcribe.py` — распознаёт речь в видео/аудио через whisper.cpp (офлайн) и выдаёт `words.json`: список слов с таймкодами. Это единый источник правды для всех следующих шагов.
- `tools/tighten.py` — вырезает реальные паузы тишины (по анализу громкости через ffmpeg), не трогая слова.
- `tools/broll.py` — вставляет b-roll (перебивки) поверх основного видео по таймкодам — автоматически по кругу из своей папки с роликами, либо по готовому JSON-плану. Звук остаётся от основного видео — голос звучит под перебивкой.
- `tools/captions.py` — накладывает субтитры на видео по `words.json` (генерирует `.ass`-субтитры и прожигает их через ffmpeg). Запускается последним перед финальным рендером, чтобы текст оставался видимым даже поверх b-roll. Размер холста под субтитры подхватывается автоматически из самого видео.
- `tools/render_reels.py` — финальный шаг: приводит видео к формату Reels (1080×1920, 30fps, h264, yuv420p, faststart). Если исходник не вертикальный, заполняет пустые поля размытым увеличенным фоном (можно переключить на чёрные поля или обрезку по центру).

## Порядок использования

Важно: транскрипцию нужно снимать **после** нарезки, а не до — иначе тайминги слов и итоговое видео разъедутся. b-roll вставляется до субтитров — тогда текст прожигается уже поверх перебивок и не пропадает.

```bash
# 1. Нарезаем паузы в исходнике
python tools/tighten.py --in raw.mp4 --out tight.mp4

# 2. Транскрибируем УЖЕ нарезанное видео
python tools/transcribe.py --in tight.mp4 --out words.json

# 3. (опционально) Вставляем b-roll поверх видео
python tools/broll.py --in tight.mp4 --broll-dir broll/ --auto \
    --interval 8 --duration 2.5 --out tight_broll.mp4 --out-plan broll_plan.json

# 4. Накладываем субтитры по свежим таймкодам (на видео с b-roll или без него)
python tools/captions.py --in tight_broll.mp4 --words words.json --out final_subs.mp4

# 5. Приводим к финальному формату Reels
python tools/render_reels.py --in final_subs.mp4 --out reel_v1.mp4
```

Подробности установки зависимостей (whisper.cpp, модель, ffmpeg) — в [`docs/setup.md`](docs/setup.md).
